# 填一张登记表，审核通过后插件就会出现在商店里。

  1. 按开发文档写好插件：清单里填写作者、许可证和完整的月璃版本区间，只从插件门面导入宿主类型，不要提交 config.toml。
  2. 在插件仓库打 Tag，写成 vX.Y.Z 或 X.Y.Z，并与清单里的版本一致。
  3. 填写登记表：插件 id、仓库地址、分类和说明。首次登记需要维护者批准。
  4. 之后每次发布新 Tag，索引会定时同步、检查与审核，通过后自动收录。
